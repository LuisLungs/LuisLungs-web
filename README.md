# Luis Lungs · Portafolio UGC

Página web de una sola página para **Luis Gaitán De Armas (@luis_lungs)**, creador UGC de deporte y bienestar.

## Qué archivo es cada cosa

| Archivo / carpeta | Para qué sirve |
|---|---|
| `index.html` | **Todos los textos** de la página. Busca los emojis 📸 🎬 🏷️ ✏️: marcan lo que debes cambiar. |
| `assets/img/hero.jpg` | Foto de portada (tú corriendo). |
| `assets/img/video-1.jpg` … `video-4.jpg` | Portada de cada video (vertical, 720 × 1280). |
| `assets/videos/video-1.mp4` … `video-4.mp4` | Tus videos (vertical 9:16). |
| `assets/logos/*.svg` | Logos de Fundación Valle del Lili, ACODET y Carrera ReNacer 5K. |
| `assets/img/og-image.jpg` | Imagen que sale al compartir el link en WhatsApp o Instagram (1200 × 630). |
| `styles.css` | Colores y diseño (no hace falta tocarlo). |
| `script.js` | Animaciones y videos (no hace falta tocarlo). |

**Truco:** si guardas tu foto o video con **exactamente el mismo nombre** que el archivo de muestra, no tienes que cambiar nada más.

## Antes de subir fotos y videos: comprímelos

- **Fotos:** entra a <https://squoosh.app>, arrastra la foto, elige formato **MozJPEG**, calidad ~75, y reduce el ancho a 1600 px (portada) o 720 px (portadas de video). Meta: menos de 250 KB.
- **Videos:** usa **HandBrake** (gratis, <https://handbrake.fr>) con el ajuste "Fast 720p30", o <https://www.freeconvert.com/video-compressor>. Meta: menos de 8 MB por video.
- **Logos:** mejor en SVG o PNG con fondo transparente y en versión clara/blanca (el fondo de la página es oscuro).
